# 履修登録シミュレーター PWA 1.2.2のソース

ビルド・公開・操作手順は1つ上のREADME.mdを参照してください。2026年10月24日に学期の絞り込み、必修追加ボタン、科目区分表示を更新しました。

1.2.1ではsrc/planning.cssで、授業がある時間割の枠の追加ボタンを非表示にしました。履修状態や保存形式は変更していません。

1.2.2では時間割・オンデマンド・時間割下の科目一覧の操作ボタンをオン・オフする表示設定を追加しました。displaySettings.showCourseActionsで設定を保持し、初期値はfalseです。詳細画面や他のページの操作は引き続き利用できます。

|場所|役割|
|---|---|
|src/domain/engine.js|履修判定、科目情報、明示的に呼び出す必修の一括追加|
|src/app/mutations.js|必修追加ボタン、履修状態、削除などの操作|
|src/ui/common.js|学期の表示条件、科目区分、共通部品|
|src/ui/timetable.js・src/ui/planning-additions.js|時間割、実日付、オンデマンド、必修追加の案内|
|src/planning.css|追加した画面要素のスタイル|
|src/pwa/|マニフェスト、キャッシュ、更新、インストール、アイコン|
|data/courses.json|従来の科目データ|
|tests/term-and-button.test.cjs|通年・前後期の表示、ボタン、区分表示の確認|

旧保存データとの互換性のためrequiredAutofill.enabledとskippedを読み書きできますが、enabledの値による自動実行は行いません。UIからの一括追加はボタンだけが呼び出します。描画処理は履修計画を追加しません。

固定した22シナリオは、新設欄・科目区分表示・必修追加設定を除いた従来の画面と操作を比較します。元のfixturesは書き換えていません。付属テストの画面確認は模擬DOMによるものです。実ブラウザの確認範囲は1つ上の検証結果.mdに記載しています。
