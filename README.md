# 履修登録シミュレーター PWA 1.2.3

## 変更内容

- 「木曜3限の授業を選ぶ」などの授業選択画面で、科目名の下に科目区分を表示します。オンデマンドの授業選択画面にも同じ表示を追加しました。
- 時間割の「操作ボタンを表示」で、時間割・オンデマンド・「この期間の科目」の「修得済みにする・科目編集・削除」をオン・オフできます。初期状態は非表示です。表示設定は端末保存とJSON書き出しに含まれ、再起動後も保持します。非表示でも科目名を押した詳細画面から操作できます。
- 授業を配置した時間割の枠では「授業を選ぶ」を非表示にします。空き枠には表示し、授業を削除して空き枠に戻すと再表示します。科目名からの編集・修得状態の変更・削除は引き続き利用できます。
- 通年科目をすべての学期に表示します。科目は1つの登録を参照し、表示のために計画や単位を重複させません。
- 「前期」は前期の授業と通年だけ、「後期」は後期の授業と通年だけを表示します。授業選択、オンデマンド欄、科目検索にも同じ区別を適用します。
- 「必修を自動追加」をボタンへ変更しました。ボタンを押したときだけ、その年度の年次に合う全員必修と、選択中の目標プログラムの必修を追加します。学期にかかわらず対象年度の必修を追加し、画面には選択中の学期に合う科目を表示します。
- 初回起動、画面・年度・学期の切替、プログラム選択、旧版からの更新、再起動では必修を追加しません。削除した必修は、ボタンを再度押した場合に追加対象へ戻します。
- 時間割の週表示・実日付、オンデマンド欄、「この期間の科目」に科目区分を表示します。「総合科目」「学科基礎科目」「DSプログラム科目」など、科目情報に設定されている区分です。

## 学期の表示

|選択した学期|表示する授業|
|---|---|
|1Q・2Q|そのQの授業＋前期の授業＋通年|
|前期|前期の授業＋通年|
|3Q・4Q|そのQの授業＋後期の授業＋通年|
|後期|後期の授業＋通年|
|通年|通年の授業|

クォーター科目を前期・後期の表示から除いても、履修計画の登録は保持します。履修上限の判定は従来どおり半期・年間の計画全体を対象とします。

## 必修追加の操作

年度を選んで「必修を自動追加」を押します。登録済み・修得済みの科目は重複追加せず、既存の年度・クラス・履修状態を保持します。複数クラスがある科目は共通する曜限へ仮置きし、授業名を押して所属クラスを選べます。共通の曜限がない科目は「この期間の科目」から開いてください。

先修条件・単位上限・授業の重複などで追加できない科目は理由を表示します。修正後にもう一度ボタンを押してください。既存の計画を消して置き換える操作は行いません。

## GitHubで公開済みの旧版から更新する

同じリポジトリの同じ場所へ、次のファイルとフォルダをまとめてアップロードし、1回のコミットで上書きします。

```text
index.html
manifest.webmanifest
pwa.js
pwa.css
sw.js
icons/
```

ZIPそのものはアップロードしません。展開した中身を使い、公開元を開いてすぐにindex.htmlが見える配置にします。source/と説明書は公開に不要です。

配信が更新されたら、アプリをオンラインで開き「アプリ」→「更新を確認」→「更新して再起動」を押します。同じURL・同じ端末の保存領域で使えば、既存の計画・修得履歴を保持します。旧版で自動追加をオンにしていても、1.2.0ではボタンを押すまで必修を追加しません。

## 初めて利用する

フォルダ内の公開用ファイルをHTTPSで配信し、公開URLを開きます。「アプリ」で「オフラインの準備ができました」と表示されてから、ホーム画面やアプリ一覧へインストールしてください。iPhone・iPadはSafariの共有メニューから「ホーム画面に追加」を選びます。

初回保存後はオフラインで起動・編集できます。公式資料などの外部リンクには通信が必要です。index.htmlをダブルクリックして開くだけではPWAのインストールはできません。

元のHTMLから計画を移す場合は、元のブラウザで「書き出す」→PWAで「読み込む」を使います。保存キー shunan-course-planner-2026-v1 とJSONの version: 1 を保持しています。別URL・別ブラウザへの自動同期は行わないため、定期的にJSONを書き出して保管してください。

## ローカル確認と再生成

このフォルダで次を実行し、http://localhost:8000/ を開きます。

```text
python -m http.server 8000 --bind 127.0.0.1
```

ソースから再生成する場合はPython 3.9以降、付属テストにはNode.js 20以降を使用します。追加パッケージは不要です。

```text
cd source
python build.py
node --test tests/engine.test.cjs tests/ui.test.cjs tests/snapshots.test.cjs tests/persistence.test.cjs tests/render-cache.test.cjs tests/build.test.cjs tests/planning-additions.test.cjs tests/term-and-button.test.cjs tests/display-settings.test.cjs
```

生成済みファイルへの直接編集は再ビルドで置き換わります。変更はsource/src/へ行ってください。キャッシュの識別子は配信内容から自動生成します。元の外部資材不要の単独HTMLは、python build.py --output 任意の保存先.html でも生成できます。
